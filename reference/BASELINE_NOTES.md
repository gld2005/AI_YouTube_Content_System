# Baseline Workbook Notes

## File

`AI_YouTube_Content_Pipeline_Baseline.xlsx`

## Purpose

The workbook is the current prototype and should be used for:

- understanding the original nine-stage pipeline;
- inspecting existing example formulas and data;
- migration testing;
- preserving useful project, task, research, asset, and publishing fields;
- comparing visual improvement.

## Important interpretation

- The baseline is not the final architecture.
- It does not contain the complete script workspace, series system, packaging laboratory, approval center, evidence-card architecture, shared asset library, template system, local assistant, or macro automation described in the specification.
- Its current visual style is only a starting reference.
- Preserve useful data and formulas, but redesign or migrate structures as needed.
- Do not overwrite this baseline file.

## Locale

The current workbook uses Simplified Chinese labels. The final user-facing workbook should continue to use Simplified Chinese unless the user requests a change.
